# Shalini Kushwaha Portfolio

A responsive, static professional portfolio website for Shalini Kushwaha, tailored for Technical Account Management and Customer Success opportunities.

## Run locally

Open `index.html` in a browser, or serve this folder with any static-file server.

## Content note

The site deliberately avoids invented revenue, retention, customer-count, certification, or testimonial claims. Add outcome metrics and recommendations only when Shalini can verify and publicly share them.
